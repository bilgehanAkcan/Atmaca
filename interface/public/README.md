# Açılış logosu

Roketsan logo görselini bu dizine `roketsan.png` adıyla ekleyin.
Vite geliştirme sunucusu görseli `/roketsan.png` yolundan sunar.
Üretim derlemesinde göreli `BASE_URL` kullanıldığı için Electron `file://` yüklemesi de desteklenir.
Dosya eklenmezse splash ekranı yazılı bir logo yer tutucusu gösterir.
